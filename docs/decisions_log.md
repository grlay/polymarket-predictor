# Design decision log

| Date | Decision | Reason / consequence |
|---|---|---|
| 2026-10-27 | Implement the requested package without placing trades | Matches the planning report's research scope |
| 2026-10-27 | Distinguish implementation completion from empirical completion | Missing credentials, clean history and mature labels cannot be fabricated |
| 2026-10-27 | Use SQLite, immutable JSON and CSV manifests | Fits a single-machine student project and supports auditing |
| 2026-10-27 | Keep observation and availability separate | Publication dates and present metadata are insufficient for historical replay |
| 2026-10-27 | Default historical API downloads to unverified provenance | Prevents silent look-ahead from a successful API response |
| 2026-10-27 | Implement Data API v2 and explicitly selectable legacy history separately | Current docs describe migration; silent endpoint switching would alter semantics |
| 2026-10-27 | Exclude settlement points and ambiguous binary mappings | Prevents labels masquerading as input prices |
| 2026-10-27 | Move discovery from newest ID to recent trading volume | First real pilot found empty books on newly created markets; research selection still needs freezing |
| 2026-10-27 | Use prospective RSS summaries as baseline news source | Real pilot succeeded; GDELT returned 503 and is not treated as guaranteed access |
| 2026-10-27 | Use stateless sparse retrieval before trying dense embeddings | Avoids extra cost and future-corpus vocabulary/IDF fitting; leaves semantic retrieval as a measurable extension |
| 2026-10-27 | Keep market prices out of independent agent contexts | Makes AI incremental information clearer and reduces anchoring |
| 2026-10-27 | Include repeated-call single-agent comparator | Extra LLM calls alone could explain an apparent multi-agent gain |
| 2026-10-27 | Primary aggregation is regularized logistic stacking | Simple, inspectable and easier to fit with limited labelled data |
| 2026-10-27 | Add Bayesian logistic correction as a sensitivity model | Meets the proposed Bayesian direction without mislabelling ordinary logistic regression |
| 2026-10-27 | Use event-balanced loss and group-purged time splits | Repeated horizons/contracts are not independent observations |
| 2026-10-27 | Require label maturity at fit boundaries | An earlier forecast date alone does not make its future outcome a valid training label |
| 2026-10-27 | Include a synthetic offline backend with strict labels | Enables reproducible end-to-end testing without paid APIs; cannot support scientific conclusions |
| 2026-10-27 | Leave actual categories and split dates for informed selection | Available market coverage and observation windows have not yet been established |
| 2026-10-27 | Version config, prompts and source code in run identity | Avoids mixing predictions produced by materially different experiments |
| 2026-11-05 | Separate `configs/collect.yaml` from `config.yaml` | Watchlist edits must not change the forecasting run identity |
| 2026-11-05 | Discover markets by Gamma event tag slugs (draft watchlist) instead of top volume | `politics` alone returned non-US and tweet-count markets; scope is US politics/government; watchlist awaiting supervisor review |
| 2026-11-05 | Cap sub-markets per event (4) and markets per deadline date (25) | 80% of candidates ended 31 Dec / 1 Jan; their cutoffs fall in one week and cannot be split chronologically; the caps are logged as exclusions |
| 2026-11-05 | Resolution labels read from `/v2/resolutions` `status`/`price`; `proposed` is never a label | The earlier adapter expected a `payouts` array the live API does not return, so no label would ever have been stored |
| 2026-11-05 | Raw responses bundled per profile per day (gzip members, byte-range `raw_ref`) | One file per response would create millions of files over the collection period |
| 2026-11-05 | GDELT: 6 s spacing, long backoff, throttle text treated as failure, empty body as zero results | GDELT answers 429 or a text body when throttled; failures and empty searches must be distinguishable |
| 2026-11-05 | Track up to 300 markets (was 150) | A quote is under 1 KB, and selection caps can be applied at analysis time; markets never quoted cannot be recovered |
| 2026-11-05 | Run identity = forecast settings (LLM, retrieval, mode), prompts, model and forecasting code only | Paths, split dates, budgets and collector code must not orphan forecasts or void a freeze; hashes are now identical on Windows and Linux |
| 2026-11-05 | `run_agents --limit N` takes the newest eligible snapshots; stale snapshots are skipped and counted, not failed | Live forecasts must be generated within the delay window; the old behaviour picked the oldest snapshots and failed every one |
| 2026-11-05 | `--at` pilot snapshots are marked `*_pilot` and excluded from fitting and evaluation; training uses only the run's own dataset configuration | Protocol item 3: pilots must never be pooled with fixed-horizon research snapshots |
| 2026-11-05 | Agent context carries ISO UTC dates plus the deadline instead of epoch integers | Models misread raw epoch seconds |
| 2026-11-05 | Repeated-call baseline samples at `k_temperature` (0.7) | At temperature 0 the repeated calls are identical, which makes the specialization comparison unfair |
| 2026-11-05 | LLM client retries transient errors and unusable output within bounds; truncated output is an error; one clean stop when the call budget is spent | A single 429 or malformed reply must not permanently lose a time-critical forecast |
| 2026-11-05 | Market price age limit 900 s for the research config (was 21600 s) | The benchmark price must be as fresh as the evidence the agents see |
| 2026-11-07 | Reorder `tag_slugs`: institution-specific tags first, wide nets (`us-politics`, `united-states`, `trump`) last | A market's category is the first matching tag; on 2026-11-06 about 70% of kept markets were labelled `trump`, which says nothing about subtype |
| 2026-11-07 | Add tags `house-of-representatives`, `doj`, `dhs`, `hegseth`; try `senate-elections` and drop it | Slugs verified on Gamma 2026-11-06. `senate-elections` passed 9 markets, none eligible that other tags did not already catch (Overton confirmation, Alaska senator), and it added a Spanish Senate market and a vote-share margin. `senate`, `mentions`, `tweet-markets` return 404 |
| 2026-11-07 | Keep `exclude_tag_slugs: [sports]`; do not exclude `crypto`, `pop-culture`, `geopolitics`, `world` | Exclude beats include. Live check: excluding `crypto` removes 20 markets in 6 events (Clarity Act, crypto market-structure bills, a national Ethereum reserve); `pop-culture` removes 8 (weed rescheduling, FDA reclassification). These are federal actions; Layer 2 removes off-scope markets later |
| 2026-11-07 | Add question patterns: `truth social`, `insults?`, `publicly praise`, `odds leader`, `speaks? to`, `meets? with`, `visits?`, `approval rating`, `treasury yield`, `how many`. Do not add bare `post`, `meeting` or `more than N` | Each maps to a Layer 2 exclusion (decision not measurement; leader meetings and calls). Patterns use question text only. Bare patterns would also remove FOMC "meeting" markets. Dry run 2026-11-07: 377 markets removed at discovery. Discovery drops are irreversible, so patterns stay narrow |
| 2026-11-07 | `max_pages` 3 -> 8 | `trump` returned exactly 300 events with 3 pages (truncated); no other tag has more than 100 |
| 2026-11-07 | RSS: remove NPR; add White House presidential actions, Federal Register presidential documents, DOJ, Defense.gov, Al Jazeera, CBS, ABC, Axios; defer Google News query feeds | NPR returned 403 to the cloud VM's IP. Official sources suit executive-action markets. Government feeds may also block datacenter IPs: verify on the VM and drop failures. Google News needs a code change first (all items would share the source `news.google.com`). CNN politics was stale |
| 2026-11-07 | Do not schedule the `gdelt` profile; retest roughly daily | HTTP 429 from two networks (laptop and cloud VM) on 2026-11-06, after a 503 on 2026-10-27 and a failed mid-term run. Treated as optional; failures stay distinguishable from empty results |
| 2026-11-07 | Quote speed measured on the VM: 134 quotes in about 34 s (about 0.25 s per market) | Replaces the config comment "about 5 min per run". Tracking slots are not scarce at current volumes |
| 2026-11-07 | Cap decision pending. Dry run after the changes: 107 markets / 61 events with caps 4 per event and 25 per deadline day; 201 markets / 119 events with 10 and 100 | Recorded as evidence before choosing. Caps drop markets before storage and cannot be undone |
| 2026-11-07 | SUPERSEDED by the next row. Relax caps: `max_markets_per_event` 4 -> 10 and `max_markets_per_deadline_day` 25 -> 100; `max_markets_per_discovery` and `max_tracked` stay 300 | The study scope is set by Layer 2 eligibility, not by caps. Discovery drops are irreversible and storage is cheap (about 0.25 s per quote), so the time-spread and correlated-bucket rules move to analysis time. The binding constraint is the number of independent eligible storylines (about 15-20 in the 61-event list); relaxed caps roughly double the distinct events (61 -> 119). Cost: more gray cases to review manually. Report a funnel (discovered, stored, eligible, with evidence, forecast, resolved) so each filter's effect is visible |
| 2026-11-07 | Caps set to `max_markets_per_event` 100, `max_markets_per_deadline_day` 500, `max_markets_per_discovery` 600, `max_tracked` 600 (effectively no caps) | Listing what the 10/100 caps still dropped (236 markets) showed eligible-looking storylines, not low-value buckets: Trump pardon markets (DOJ pardon list is an official record), cabinet departures, trade deals, an FCC license revocation, a congressional stock-trading ban. The earlier 10/100 row rested on a wrong reading and is superseded. Dry run with no real caps: 434 markets / 222 events; a quote run is about 110-150 s at 0.25 s per market. Caps drop the least liquid markets before storage and cannot be undone; eligibility is decided by Layer 2 on stored data. `storyline_id` must be event plus subject, not event alone (different pardons are different actions; rate buckets are one). Revisit if stored markets approach 500 or quote runs approach 4 minutes |
| 2026-11-07 | Collector scheduled on the Google Cloud VM with cron (UTC): quotes every 5 min, rss every 15, discovery every 3 h, resolutions hourly, database backup daily at 03:00 with `--no-raw`; gdelt not scheduled | A quote run takes about 2 min for about 480 markets, so 5-minute runs do not overlap. Worst-case price age at a cutoff is about 300-360 s instead of about 600-660 s, so one missed run still leaves less than the 900 s limit. `--no-raw` because a same-disk copy of the raw archive protects nothing and doubles storage. The 5-minute cadence differs from `INTERVAL_MINUTES` (10) in `run_collect.py`; `collector_status` then shows more than the expected runs. Disk growth is not yet measured (rough guess 0.4-0.7 GB per day, uncertain): re-measure after 24 h and go back to 10 minutes or enlarge the disk if needed |
| 2026-11-07 | Code: RSS items from a known aggregator (`news.google.com`) take the publisher named in the `<source url>` tag as their source; all other feeds keep the link host | Retrieval caps documents per source (2 per bundle) and a source allowlist needs the real publisher; without this every Google News item would count as one source. Only listed aggregators are re-attributed so existing feeds are unchanged. Query-based Google News feeds are still not added to `rss_urls` (terms of use unchecked) |
| 2026-11-07 | Code: hand-written evidence profiles (`configs/relevance_profiles.yaml`) for the Rubio-departure and Iran-blockade storylines; a document is accepted only if it is inside the window, mentions an entity, and mentions an institution or action term; a profiled market with no accepted document is refused before any LLM call; the profile file is hashed into the forecast run identity | Shared-spec Layer 3 stage 1. Written from the question text only. Whole-word matching, with an explicit `*` for prefixes (so "department" does not match "depart"). Tightened the blockade profile the same day: a check on 252 stored documents showed two Iran-commentary pieces accepted through generic terms (`negotiat*`, talks, deal, agreement, announce*, end), so those terms were removed. Not yet validated: precision and recall must be measured on a hand-labelled audit set before this is called a method |
| 2026-11-07 | Code: `--market-id` on `build_dataset` and `run_agents`; unknown ids are an error, a requested market without a snapshot is a reported failure while the others still run, and the filter is applied before `--limit` | At the 9 Nov and 15 Nov cutoffs about six markets share the 16 Nov deadline, snapshots are ordered by cutoff then a hash, and forecasts older than 900 s are skipped, so the two target markets could be skipped. Markets are chosen before the cutoff, by hand for this pilot, never from prices or outcomes |
